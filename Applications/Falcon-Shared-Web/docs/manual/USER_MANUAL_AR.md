# دليل المستخدم العادي — Falcon Shared Web

**الفئة:** Standard User  
**اللغة:** العربية  
**النطاق:** واجهات المستخدم العامة وواجهات العميل في Shared Falcon Web

## 1. ما هو Falcon Shared Web؟

Shared Falcon Web هو واجهة العرض والتفاعل المشتركة لنظام Falcon. الواجهة تعرض المعلومات المسموح بها وتسمح بإرسال الطلبات المسموح بها، لكنها لا تصبح بحد ذاتها مصدر الحقيقة التشغيلية ولا تملك صلاحية التداول أو التنفيذ أو منح الصلاحيات.

## 2. الصفحات العامة

يمكن للمستخدم الوصول إلى الصفحات العامة التالية بدون اعتبار وجود الصفحة دليلاً على وجود صلاحية تشغيلية:

- الصفحة الرئيسية `#/home`
- التطبيقات `#/apps`
- تسجيل الدخول `#/login`
- إنشاء حساب `#/register`
- صفحة FSATS العامة `#/fsats`

## 3. بعد تسجيل الدخول

عند وجود جلسة authoritative صالحة وصلاحية وصول مناسبة، يمكن أن تظهر صفحات المستخدم التالية:

- تطبيقاتي `#/my-apps`
- لوحة FSATS `#/trader`
- الأسواق `#/markets`
- الأسواق الاستشارية `#/advisory-markets`
- المحفظة `#/portfolio`
- النشاط `#/activity`
- الذكاء والتحليل `#/ai`
- الإشعارات `#/notifications`
- الإعدادات `#/settings`

ظهور الرابط أو البطاقة لا يعني تلقائيًا أن الحساب مخول لاستخدام الميزة. إذا لم تصل صلاحية authoritative، تبقى الميزة مقفلة أو غير متاحة بدل افتراض الصلاحية.

## 4. تطبيقاتي والخطط

واجهة My Applications تعرض التطبيقات المتاحة للحساب حسب البيانات authoritative فقط. يوجد نموذجان للعرض: `STANDARD` و`VIP`.

- لا يتم افتراض السعر.
- لا يتم افتراض وجود Trial.
- لا يتم افتراض Upgrade.
- لا تعتبر رؤية خطة أو تطبيق دليلاً على entitlement.

القاعدة: `TIER_VISIBLE ≠ ENTITLED ≠ ACTION_AUTHORIZED`.

## 5. الأسواق والرسوم

صفحات الأسواق تعرض بيانات presentation فقط. بيانات السوق التي تظهر في الويب لا تصبح مدخلًا تشغيليًا لـFSATS ولا تسمح بتنفيذ صفقة.

إذا كان مصدر البيانات غير مربوط أو غير متاح، يجب أن تظهر الحالة كـUnavailable بدل اختراع سعر أو حالة.

## 6. المحفظة والنشاط

- المحفظة تعرض البيانات التي تصل من المصدر authoritative فقط.
- القيم غير المتاحة تبقى غير متاحة ولا تتحول إلى صفر.
- النشاط يحافظ على حالة الطلب والتنفيذ كما وصلت من المصدر.
- `PARTIALLY_FILLED` لا تتحول إلى `FILLED`.
- الحالة غير المعروفة لا تتحول إلى رفض أو نجاح من الواجهة.

## 7. الذكاء والتحليل

صفحة AI تعرض نتائج التحليل فقط عندما تكون النتيجة الحالية كاملة ومسموح بعرض تفاصيلها. إذا كانت النتيجة stale أو partial أو تحتاج clarification، تقل التفاصيل أو تُحجب بدل عرضها كأنها كاملة.

الويب لا ينشئ استراتيجية تداول ولا قرار تنفيذ من تلقاء نفسه.

## 8. الإشعارات والدعم

قد تعرض الإشعارات محادثات incident ودعمًا موجهًا للمستخدم. بعض الوظائف تحتاج runtime bindings حقيقية مثل:

- هوية المستخدم والجلسة
- persistence للإنتاج
- فحص أمان الصور
- Support transport
- voice runtime محلي

إذا لم تكن هذه الخدمات مربوطة، تبقى الوظيفة fail closed.

لا ترسل كلمات مرور أو مفاتيح أو أسرار داخل الدردشة. الصور التي تحتوي أسرارًا يجب رفضها.

## 9. اللغة وإمكانية الوصول

- الواجهة تدعم العربية والإنجليزية.
- العربية تعمل RTL.
- القوائم تدعم لوحة المفاتيح.
- يوجد visible keyboard focus.
- يوجد skip link للوصول للمحتوى الرئيسي.
- التصميم يدعم reduced motion وforced-colors حيث ينطبق.

## 10. ماذا يعني Preview أو Unavailable؟

`Preview` يعني عرضًا توضيحيًا وليس حقيقة live.  
`Unavailable` يعني أن المصدر authoritative غير متاح أو غير مربوط.  
لا يتم تحويل أي منهما إلى حالة Live تلقائيًا.

## 11. قواعد الأمان للمستخدم

- لا تعتبر وجود زر دليلاً على وجود صلاحية.
- لا تشارك credentials أو secrets في الحقول غير المخصصة لها.
- لا تعتبر screenshot دليلًا نهائيًا على حقيقة broker.
- لا تعتبر إشعارًا أو رسالة Support موافقة تداول أو Business Authorization.
- إذا كانت حالة معلومة غير واضحة، تعامل معها كغير متاحة حتى يتم تأكيدها من المصدر authoritative.

## 12. الحالة الحالية

Shared Web جاهز من جهة التحضير للربط مع Foundation، لكن الربط الفعلي والتشغيل والـdeployment والـprovider connectivity تتم فقط بعملية منفصلة ومصرح بها. هذا الدليل لا يدعي أن البيئة الحية مربوطة الآن.
