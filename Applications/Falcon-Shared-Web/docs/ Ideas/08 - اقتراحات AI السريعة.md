# Shared Falcon Web - اقتراحات AI السريعة

**Status:** `DRAFT / DISCUSSION ONLY`

هذا الملف يسجل قرار تجربة الـAI contextual prompt داخل FSATS. هذا تخطيط UX/Product فقط ولا يمنح implementation/runtime/execution authority.

---

## 1. Contextual Prompt

عندما يكون المستخدم على صفحة ذات سياق واضح، مثل Microsoft، لا يبدأ الـAI الحديث تلقائيًا ولا يفرض تحليلًا أو توصية.

بدل ذلك يظهر له prompt صغير وغير متطفل مثل:

```text
اسألني عن Microsoft
```

الهدف هو إعطاء المستخدم إحساسًا بأن المساعدة موجودة وجاهزة بدون اقتحام تجربته أو إعطائه نصيحة لم يطلبها.

```text
CONTEXT AWARENESS != UNSOLICITED ADVICE
PAGE OPEN != RECOMMENDATION
USER CONTROL > AI INTERRUPTION
```

---

## 2. فتح الـSide Panel

عندما يضغط المستخدم على `اسألني عن Microsoft` يفتح الـAI Side Panel مع اقتراحات سريعة مرتبطة بالسياق الحالي.

أمثلة UX عامة يمكن استخدامها عندما تكون مناسبة للسياق:

```text
اعمللي تحليل
اشرحلي الشركة
شو مخاطرها
قارنها مع غيرها
شيء آخر
```

هذه الاقتراحات shortcuts فقط، وليست قائمة إلزامية أو حدودًا للمحادثة.

يجب أن يبقى حقل الكتابة الطبيعي ظاهرًا ومتاحًا دائمًا حتى يستطيع المستخدم أن يكتب أي سؤال أو طلب يريده مباشرة بدون اختيار أي اقتراح.

```text
SUGGESTED PROMPTS = OPTIONAL SHORTCUTS
FREE-TEXT INPUT = ALWAYS AVAILABLE
SUGGESTION LIST != ALLOWED INTENT LIST
```

إذا اختار المستخدم `شيء آخر` يمكن إبراز حقل الكتابة أو وضع المؤشر فيه، لكن المستخدم يستطيع أصلًا الكتابة مباشرة دون الضغط على هذا الخيار.

## 3. Dynamic / Contextual Suggestions

قرار الـOwner الحالي:

**الاقتراحات السريعة لا تكون قائمة ثابتة تتكرر لكل سهم أو صفحة. يتم اختيارها بصورة ديناميكية حسب السياق الحالي المسموح والموثوق وما يوفّره FSATS بصورة authoritative.**

الهدف من الديناميكية هو أن يشعر المستخدم أن Falcon منتبه لما يشاهده الآن ويقدم له مدخلًا مفيدًا للمحادثة، بدل أن يعرض نفس الأزرار أينما ذهب.

مثال UX فقط، إذا كانت الحالة الحالية والمعلومات authoritative تدعم ذلك، قد تظهر اقتراحات من نوع:

```text
ليش Microsoft متحركة اليوم؟
شو أهم المخاطر الحالية؟
اشرحلي اللي ظاهر قدامي
قارنها مع شركة مشابهة
```

وإذا كان هناك حدث أو نتيجة مالية أو حركة مهمة فعلية ومعروفة من FSATS، يمكن أن يتغير أحد الاقتراحات ليشير إلى الشيء المهم للمستخدم. أما إذا لم يوجد سياق موثوق كافٍ، فيتم الرجوع إلى اقتراحات عامة وآمنة بدل اختراع حدث أو تفسير.

القواعد الحالية:

- الـDynamic Suggestions تستند إلى page context ومعلومات/حالات authoritative متاحة للمستخدم.
- الـWeb أو الـAI لا يخترعان market/business truth فقط لصناعة suggestion جذاب.
- freshness / stale / unknown / unavailable لا يجوز إخفاؤها إذا كانت تؤثر على معنى الاقتراح.
- الاقتراح الديناميكي لا يعني أن Falcon يوصي بالسهم أو يؤيده.
- ظهور اقتراح متعلق بحركة أو مخاطرة لا يعني أن التحليل أُنجز قبل أن يطلبه المستخدم.
- حقل free-text يبقى متاحًا دائمًا، والمستخدم حر في تجاهل كل الاقتراحات.

```text
DYNAMIC SUGGESTION = CONTEXTUAL HELP
!=
RECOMMENDATION

CONTEXT AWARENESS = ATTENTIVE UX
!=
UNSOLICITED ADVICE

APPLICATION TRUTH -> SUGGESTION CONTEXT
WEB/AI MUST NOT INVENT BUSINESS TRUTH
```

## 4. Respectful Adaptive Guidance

يجوز للـAI أن يكيّف عمق الاقتراحات وطريقة الشرح مع أسلوب المستخدم واحتياجه الظاهر من الحوار، مثل إعطاء مدخل أبسط لمن يفضّل الشرح المباشر أو اقتراح أعمق لمن يطلب تحليلًا تقنيًا متقدمًا.

لكن هذا التكيّف يجب ألا يتحول إلى تصنيف جارح أو أسلوب يشعر المستخدم أنه أقل فهمًا أو خبرة.

مبادئ UX الحالية:

- لا تُعرض للمستخدم تسميات مثل `مبتدئ` أو `غير خبير` كحكم عليه لمجرد تبسيط التجربة.
- لا يستخدم الـAI عبارات من نوع: `واضح أنك لا تعرف` أو `هذا صعب عليك` أو أي صياغة تقلل من المستخدم.
- التبسيط يُقدّم باحترام، وكأنه اختيار في أسلوب الشرح وليس تصحيحًا لقدرات الشخص.
- عندما يكون سؤال المستخدم جيدًا أو يلتقط نقطة مهمة، يمكن للـAI أن يعترف بقيمة السؤال بشكل طبيعي بدون مبالغة أو مجاملة مصطنعة.
- إذا احتاج الـAI لتصحيح فهم خاطئ، يصحح الفكرة نفسها بهدوء ووضوح دون مهاجمة الشخص أو تقييم ذكائه.
- الاقتراحات يمكن أن تصبح أعمق تدريجيًا مع الحوار، أو أبسط عند طلب المستخدم ذلك، بدون أن يشعر أن Falcon وضعه في "فئة" ثابتة.

أمثلة نبرة مناسبة:

```text
خليني أبسطها أكثر.

أهم نقطة هون هي...

سؤالك يلمس نقطة مهمة، والفرق الأساسي هو...

إذا بدك ندخل أعمق، فينا نحللها من ناحية السيولة والمخاطر.
```

أمثلة نبرة غير مرغوبة:

```text
بما أنك مبتدئ...

واضح أنك لا تعرف كيف يعمل هذا.

هذا الموضوع متقدم عليك.
```

```text
ADAPT TO THE USER
!=
LABEL THE USER

SIMPLIFY THE EXPLANATION
!=
DIMINISH THE PERSON

CORRECT THE IDEA
!=
JUDGE THE USER
```

الهدف هو أن يشعر المستخدم أن Falcon يفهم طريقته ويتقدم معه، لا أنه يقيسه أو يختبره.

---

## 5. User Control

الهدف من الاقتراحات هو مساعدة المستخدم الذي قد لا يعرف ماذا يسأل في لحظته الحالية، بدون تحويل المحادثة إلى wizard أو menu-driven interface وبدون افتراض مستوى ثابت له.

```text
GUIDANCE WITHOUT RESTRICTION
```

الـAI يبقى natural-language interface. الاقتراحات تساعد على البداية فقط، والمستخدم يظل صاحب القرار في موضوع المحادثة وصياغة طلبه.

---

## 6. Domain Truth Boundary

الاقتراحات نفسها لا تنشئ تحليلًا أو recommendation أو execution authority.

أي تحليل أو مقارنة أو مخاطرة معروضة للمستخدم تعتمد على authoritative FSATS output عندما تكون متاحة عبر العقود governed مستقبلًا.

```text
PROMPT CLICK != ANALYSIS TRUTH
PROMPT CLICK != RECOMMENDATION
PROMPT CLICK != EXECUTION
```

---

هذا الملف لا يعني `APPROVED` ولا `IMPLEMENTATION AUTHORIZED`.
