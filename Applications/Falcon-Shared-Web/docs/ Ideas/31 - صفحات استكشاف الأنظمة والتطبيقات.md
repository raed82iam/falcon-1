# Shared Falcon Web - صفحات استكشاف الأنظمة والتطبيقات

**Status:** `OWNER-DIRECTED UX DECISION / ACTIVE IMPLEMENTATION INPUT`

هذا الملف يسجل قرار الـProject Owner بتاريخ 2026-08-15 بخصوص سلوك زر `استكشف التطبيق / Discover` في Public Falcon Web.

الهدف هو أن تكون Falcon صادقة وواضحة مع الزائر: لا نعرض اسم Application فقط، ولا نستخدم لغة تسويقية غامضة، بل نعطي شرحًا بسيطًا وسهل الفهم لما يفعله النظام/التطبيق فعليًا، مع وسائط بصرية قصيرة تساعد على الفهم.

---

## 1. قاعدة الاستكشاف

عند ضغط المستخدم على:

`استكشف التطبيق / Discover`

يتم فتح صفحة تعريف عامة مخصصة لذلك الـSystem/Application.

الصفحة ليست Dashboard تشغيلية، وليست صفحة داخلية حساسة، وليست دليلاً على الاشتراك أو الصلاحية أو الجاهزية التشغيلية.

```text
DISCOVER PAGE != RUNTIME DASHBOARD
DISCOVER PAGE != SUBSCRIPTION GRANT
DISCOVER PAGE != ENTITLEMENT GRANT
DISCOVER PAGE != OPERATIONAL AUTHORITY
```

---

## 2. أسلوب الشرح

الشرح يجب أن يكون:

- قصيرًا وواضحًا.
- مفهومًا لغير التقنيين.
- يشرح الفائدة والعمل الحقيقي بدون jargon زائد.
- لا يدعي capabilities أو licensing أو readiness غير موجودة.
- لا يحول internal architecture إلى مادة مربكة للمستخدم.
- عربي/إنجليزي بنفس المعنى.

الترتيب المفضل:

```text
ما هو؟
↓
ماذا يفعل؟
↓
كيف يساعد المستخدم؟
↓
كيف يعمل بشكل مبسط؟
↓
وسائط بصرية قصيرة
↓
CTA مناسب حسب الحالة الفعلية
```

---

## 3. الوسائط البصرية

صفحة الاستكشاف يمكن أن تستخدم واحدًا أو أكثر من التالي:

- صور متحركة خفيفة.
- Motion diagrams مبسطة.
- Short product walkthrough.
- فيديو قصير يشرح الفكرة أو تدفق الاستخدام.
- لقطات واجهة حقيقية أو mock/demo واضح الوسم عندما لا تكون live.

الوسائط يجب أن تكون تعليمية لا استعراضية فقط، وأن تحترم الأداء وإمكانية الوصول.

```text
ANIMATION = EXPLANATION AID
VIDEO = OPTIONAL EXPLANATION AID
MEDIA != PROOF_OF_LIVE_CAPABILITY
DEMO_MEDIA != LIVE_RUNTIME_TRUTH
```

إذا كان `prefers-reduced-motion` فعالًا، يجب توفير تجربة ثابتة أو أقل حركة بدل فرض animation على المستخدم.

الفيديو لا يعمل بصوت تلقائي. إذا استُخدم autoplay بصري صامت، يجب أن يكون قصيرًا، muted، قابلًا للإيقاف، ولا يكون ضروريًا لفهم المحتوى.

---

## 4. FSATS والـChild Applications

`Falcon Self-Aware Trading System (FSATS)` يحصل على Discover Page على مستوى النظام تشرح بصورة مبسطة أنه نظام التداول داخل Falcon OS.

ويظهر داخله التسلسل الصحيح:

```text
FSATS
├── FSATA
├── FSAPMA
├── FTGA
├── FSTSimA
└── APP-RSC
```

كل واحد من التطبيقات الخمسة يمكن أن يملك Discover detail خاصًا به يشرح وظيفته باختصار، بدون تقديمه كـFalcon top-level system مستقل.

مثال presentation flow:

```text
Falcon Public Home
↓
FSATS
[ استكشف النظام ]
↓
FSATS Discover Page
├── ما هو FSATS؟
├── كيف تعمل منظومة التداول بصورة مبسطة؟
├── Animated/System flow
├── FSATA       [ استكشف ]
├── FSAPMA      [ استكشف ]
├── FTGA        [ استكشف ]
├── FSTSimA     [ استكشف ]
└── APP-RSC     [ استكشف ]
```

---

## 5. الأنظمة المستقبلية غير التداولية

أي نظام مستقبلي مثل Accounting أو Warehouse يكون sibling لـFSATS تحت Falcon OS، وله Discover Page مستقلة عندما يصبح موجودًا أو قابلًا للتقديم العام.

لا يتم وضعه داخل FSATS ولا استخدام نفس narrative الخاص بالتداول له.

```text
FUTURE_NON_TRADING_SYSTEM -> OWN_DISCOVER_PAGE
FUTURE_NON_TRADING_SYSTEM != FSATS_CHILD
```

---

## 6. الصدق التسويقي

المحتوى العام يجب أن يميز بوضوح بين:

- available/current public capability؛
- development/demo؛
- future/candidate؛
- unavailable/not yet offered.

لا يجوز لصور أو فيديو أو animation أن توحي بأن ميزة live أو مرخصة أو متاحة إذا لم تكن كذلك.

إذا كان المحتوى يستخدم demo/mock media، يظهر ذلك بشكل واضح وغير مزعج.

هذه القاعدة تكمل ولا تستبدل:

`docs/ Ideas/30 - حدود الادعاءات القانونية والتسويقية.md`

---

## 7. CTA حسب الحالة

زر النهاية لا يكون ثابتًا لكل الحالات.

أمثلة:

```text
AVAILABLE + ENTITLEMENT PATH EXISTS
-> Sign In / Get Started / Open

PUBLIC DISCOVERY ONLY
-> Learn More / Sign In

FUTURE OR NOT OFFERED
-> Coming Later / Follow Updates

UNAVAILABLE
-> No false activation CTA
```

Shared Web لا يخترع availability أو subscription truth من عنده.

---

## 8. قاعدة التصميم

Discover Pages تتبع الهوية البصرية المعتمدة للـFalcon Public Home:

- Dark Falcon visual language.
- واضحة ونظيفة.
- شرح بصري محسوب.
- بدون تحويل الصفحة إلى trading dashboard.
- Animation/video تستخدم لتبسيط الفكرة لا لزيادة الضجيج.

الهدف:

**الزائر يفهم وظيفة النظام/التطبيق خلال وقت قصير بدون حاجة لقراءة مستند تقني.**

هذا القرار Web-owned presentation/UX. لا يغير Application/Foundation business semantics، ولا يمنح runtime/deployment/connectivity/entitlement authority.
