# Shared Falcon Web - اقتراحات AI السريعة داخل FSATS

**Status:** `DRAFT / DISCUSSION ONLY`

هذا الملف يسجل قرار UX الخاص بالاقتراحات السريعة التي تظهر للمستخدم عند فتح AI Assistant من صفحة ذات سياق واضح داخل FSATS.

هذا تخطيط UX/Product فقط ولا يمنح implementation/runtime/execution authority.

---

## 1. قرار Owner الحالي

عندما يضغط المستخدم contextual prompt مثل:

```text
اسألني عن Microsoft
```

يفتح الـAI Side Panel مع اقتراحات جاهزة تساعد المستخدم على البدء بسرعة، مع بقاء حقل المحادثة الحر متاحًا دائمًا.

الاقتراحات الحالية:

```text
اعمللي تحليل
اشرحلي الشركة
شو مخاطرها
قارنها مع غيرها
شيء آخر
```

---

## 2. معنى `شيء آخر`

`شيء آخر` لا يفرض workflow جديدًا ولا يقيّد المستخدم بقائمة ثابتة.

عند اختياره، يبقى المستخدم حرًا بكتابة أي طلب طبيعي، مثل:

```text
احكيلي عن آخر نتائجها
شو نقاط القوة والضعف؟
شو الفرق بينها وبين Apple؟
فسرلي وضعها بطريقة بسيطة
```

المبدأ:

```text
QUICK PROMPTS = OPTIONAL STARTING POINTS
!=
ONLY ALLOWED USER REQUESTS
```

و:

```text
USER CAN ALWAYS TYPE A FREE-FORM REQUEST
```

---

## 3. قواعد UX

- الاقتراحات تظهر لتسهيل البداية خصوصًا للمستخدم المبتدئ.
- لا يجب أن تبدو كأوامر تقنية أو لغة تداول معقدة.
- الاقتراحات مرتبطة بسياق الصفحة الحالية عندما يكون ذلك مسموحًا ومتوفرًا authoritative.
- اختيار أي اقتراح يفتح محادثة عادية ويمكن للمستخدم بعدها تغيير الموضوع بحرية.
- لا يعني أي اقتراح recommendation أو execution authority.
- النصوص النهائية وترتيب الأزرار ستُحسم لاحقًا في wireframes.
