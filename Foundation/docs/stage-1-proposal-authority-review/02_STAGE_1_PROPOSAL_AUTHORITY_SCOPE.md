# 02 - Stage 1 Proposal Authority Scope

## Purpose of the authority

If granted, `STAGE_1_PROPOSAL_AUTHORITY` allows preparation of a complete
Stage 1 proposal package only.

## Limited authority that could be granted

The proposed authority is limited to:

- inspecting the canonical baseline;
- defining the exact Stage 1 objective;
- identifying Stage 1 deliverables;
- defining implementation boundaries;
- defining prerequisites;
- defining verification scenarios;
- defining evidence requirements;
- defining environment and dependency requirements;
- defining security and isolation controls;
- defining rollback and stop conditions;
- preparing a future Stage 1 execution-authorization package.

## What this authority does not include

It does not include:

- implementation;
- executable artifact preparation;
- dependency installation;
- environment activation;
- runtime execution;
- deployment;
- production preparation;
- cloud activation;
- external connectivity;
- financial activity;
- modification of the canonical baseline;
- automatic Stage 1 authorization.

## Expected outcome if granted

The result of this authority would be a complete, reviewable Stage 1 proposal
that can later be considered for execution authorization by separate Owner
decision.
