# 04 - Stage 1 Proposal Boundaries and Non-Authorities

## Boundaries

The Stage 1 proposal, if authorized, must remain within the activated canonical
baseline and must not alter the closed Stage 0 record.

The proposal must respect:

- Falcon Constitution;
- Document Authority;
- the activated AMD-008 documentary alignment;
- Foundation/Application separation;
- awareness boundaries;
- Guardian boundaries;
- financial restrictions;
- external-connection restrictions.

## Non-authorities

The following are explicitly prohibited in this package:

- implementation code;
- executable artifacts;
- dependency installation;
- environment activation;
- runtime execution;
- deployment;
- production preparation;
- cloud activation;
- external connectivity;
- financial activity;
- modification of the canonical baseline;
- automatic Stage 1 authorization.

## Classification rule

This package is only about proposal authority. It must not be treated as Stage 1
execution authority.
