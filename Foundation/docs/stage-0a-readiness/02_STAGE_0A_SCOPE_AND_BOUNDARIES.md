# Stage 0A Scope and Boundaries

**Canonical Status:** Defined but not authorized  
**Stage 0A Status:** `BLOCKED`

## 1. Exact Scope Determination

Stage 0A scope is limited to governed Foundation preparation and read-only review of bounded bootstrap candidates.

It includes only the activities the canonical baseline describes as preparation, candidate construction, verification setup, evidence capture, and bootstrap sequencing support.

## 2. Permitted During Stage 0A If Later Authorized

- documentary preparation only;
- candidate artifact creation;
- read-only inspection;
- bounded evidence capture;
- construction of exact preparation candidates;
- bootstrap sequencing work that remains non-operational.

## 3. Prohibited Even if Stage 0A Is Later Authorized

- implementation code;
- executable code;
- dependency installation as operational setup;
- environment configuration that creates operational trust;
- provider activation;
- external connectivity;
- financial activity;
- Stage 1 work;
- any change to activated canonical documents or archived predecessors.

## 4. Boundary Rule

Preparation SHALL not become authority.

Candidate construction SHALL not become activation.

Read-only inspection SHALL not become implementation.

## 5. Conclusion

Stage 0A is bounded, but not presently authorized.
