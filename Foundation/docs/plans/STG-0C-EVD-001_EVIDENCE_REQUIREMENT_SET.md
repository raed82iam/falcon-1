## 3. Completeness

`COMPLETE`, `PARTIAL`, `INCOMPLETE`, and `INVALID` retain their governed meanings. Only `COMPLETE`, integrity-valid, scope-valid evidence may support an Activation decision.

## 4. Root Case

Each Activation decision shall reference exactly one immutable Root Verification Evidence Set preserving obligations, evidence, evaluations, contexts and provenance, validity, completeness, reviews, Challenges, decision, and non-authorities.

## 5. Current Effect

This candidate creates no evidence session and authorizes no evaluation.
