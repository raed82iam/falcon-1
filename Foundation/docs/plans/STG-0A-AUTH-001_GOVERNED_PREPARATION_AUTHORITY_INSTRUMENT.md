**Financial Authority:** Not Granted

## 1. Purpose

This instrument defines the exact authority governing Stage 0A preparation.

It is effective only within the limits approved by GOV-048.

## 2. Authorized Purpose

This instrument authorizes only bounded local Windows preparation for Falcon’s non-financial Foundation work.

The authorized purpose is to prepare the local workspace, collect environment facts, define evidence locations, confirm financial isolation, and prepare for later Stage 0B proposal.

## 3. Authorized Scope

Stage 0A may:

- inspect the local Falcon repository;
- create Stage 0A evidence directories;
- create preparation manifests;
- document installed tool versions;
- inspect non-secret environment facts;
- create non-executable documentation artifacts;
- prepare local folder structure for later governed work;
- verify that prohibited financial material is absent from the preparation scope;
- verify that prohibited secrets are absent from the preparation scope;
- and produce a Stage 0A completion report.

## 4. Prohibited Scope

Stage 0A SHALL NOT:

- implement Falcon code;
- install or download tools without separate explicit permission;
- execute Falcon runtime;
- run verification plans;
- activate Providers, Profiles, Gates, Pipelines, runners, or environments;
- create or use Oracle Cloud resources;
- connect to brokers, exchanges, banks, custodians, or market data providers;
- use real credentials or secrets;
- use real financial data;
- create orders, positions, portfolios, or capital-bearing actions;
- or claim readiness for Stage 0B without evidence review.

## 5. Required Companion Documents

This authority depends on the following approved documents:

- `STG-0A-BEC-001`;
- `STG-0A-EVD-001`;
- `STG-0A-FIN-001`;
- `STG-0A-ENV-001`;
- `STG-0A-EXIT-001`.

All must be approved before Stage 0A preparation begins.

## 6. Stop Conditions

Stage 0A SHALL stop if authority is unclear, evidence cannot be preserved, prohibited secrets or financial material are discovered, scope is exceeded, or any action would imply implementation, Activation, production, cloud deployment, or financial activity.

## 7. Expiration

This Authority Instrument expires at the earlier of:

- completion of the Stage 0A completion report;
- revocation by Project Owner;
- material scope challenge;
- evidence failure;
- or 7 calendar days after approval.
