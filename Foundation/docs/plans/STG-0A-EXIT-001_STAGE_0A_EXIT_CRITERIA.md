## 1. Purpose

This document defines when Stage 0A may be considered complete.

It prevents preparation from silently becoming an open-ended work state.

## 2. Completion Criteria

Stage 0A may be completed only when:

- approved authority existed before preparation began;
- Bootstrap Execution Context was followed;
- repository status before and after preparation is recorded;
- required evidence is complete;
- financial isolation is proven;
- prohibited secrets are absent;
- environment facts are recorded;
- all file changes are summarized;
- unresolved risks are listed;
- stop conditions were reviewed;
- cleanup is complete or intentionally preserved;
- and a final Stage 0A completion report is produced.

## 3. Failure Criteria

Stage 0A fails if:

- authority is missing or exceeded;
- evidence is incomplete without accepted explanation;
- prohibited financial material is discovered;
- prohibited secrets are discovered;
- scope expands into implementation;
- cloud deployment is required;
- or Falcon’s Vision, Constitution, Guardian model, or capital protection is violated.

## 4. Exit Decision

Stage 0A completion may recommend whether Stage 0B should be proposed.

It SHALL NOT authorize Stage 0B.

## 5. Required Final Statement

The completion report SHALL state one of:

```text
STAGE 0A COMPLETE — STAGE 0B MAY BE PROPOSED
STAGE 0A INCOMPLETE — REMEDIATION REQUIRED
STAGE 0A STOPPED — AUTHORITY REVIEW REQUIRED
```
