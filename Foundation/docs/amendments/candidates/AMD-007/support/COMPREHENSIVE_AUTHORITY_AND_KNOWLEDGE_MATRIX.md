# Comprehensive Authority and Knowledge Matrix

**Status:** Proposed

| Entity | Knows/observes | May request/decide | May execute/repair | May approve | Prohibited |
|---|---|---|---|---|---|
| Project Owner | governed decision package | constitutional/project decisions | no implied execution | exact delegated scope | silent technical self-validation |
| Architecture Board | architecture and impact | architecture acceptance when constituted | none | architecture only | Owner/constitutional/production authority |
| FSA | Foundation technical condition/conformance | repair/candidate proposal | approved repair; isolated candidate work when separately authorized | conformance assessment only | business meaning; self-approval |
| FFG | technical threat/criticality | Platform restriction/isolation/release condition | no ownership transfer | none outside mandate | business judgment; self-expansion |
| AUT-001 | authority chain/context | permission decision | authority-state enforcement | none | create jurisdiction |
| MSA | one Application’s complete business/technical awareness | Application-level evaluation and escalation | Application-owned actions if authorized | business/domain and Application readiness only | Foundation or another Application’s ownership |
| LSA | one major branch inside one Application | branch evaluation and escalation to parent MSA | branch-owned actions if authorized | branch readiness only | complete-Application, cross-Application, or Foundation authority |
| CSA | one eligible component | component proposal/escalation | bounded component action | none protected | parent/Foundation authority |
| Application Guardian | own domain protection | own restrictions; CON-022 requests | domain action via competent owner | none outside mandate | control another Application |
| Trading Guardian | Trading protection state | Trading restrictions; CON-022 requests | no broker execution | none outside mandate | Foundation/other-App control |
| Runtime | runtime state | execution feasibility/result | runtime action | none | invent protection authority |
| Lifecycle | lifecycle state | transition validation/result | lifecycle transition | none | release Guardian restriction |
| Resource Management | resource state | allocation feasibility | ordinary/emergency allocation | none | business priority invention |
| Service Bus | routes/delivery | admission/delivery result | transport | none | payload business interpretation |
| FIL | envelope/schema semantics | validation result | representation only | none | authority or business decision |
| Persistence | durable technical state | persistence/reconciliation result | store/retrieve | none | redefine ownership |
| Health Monitoring | health evidence | health assessment | observe | none | Safe Mode decision |
| Security | identity/trust/security state | security restriction | security controls | scoped security acceptance | universal authority |

Knowledge, observation, capability, and execution never create jurisdiction.
