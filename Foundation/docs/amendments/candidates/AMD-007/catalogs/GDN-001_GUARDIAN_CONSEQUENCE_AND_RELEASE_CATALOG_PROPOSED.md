# GDN-001 — Guardian Consequence and Release Catalog

**Identifier:** GDN-001 — Proposed Reservation  
**Version:** Proposed 1.0  
**Status:** Proposed  
**Policy Owner:** AUT-003

| Class | Maximum default scope | Autonomous review ceiling | Minimum release authority |
|---|---|---|---|
| G0 | observation | policy-defined | originating protection authority |
| G1 | one capability/route | short bounded interval | FFG plus verified condition |
| G2 | component/runtime/Application | bounded interval | FFG plus independent verifier |
| G3 | multi-component/Platform containment | stricter bounded interval | delegated Protection Release Authority plus FFG condition |
| G4 | Platform Safe | continuous review | Project Owner or explicitly delegated Protection Release Authority plus independent verification |
| G5 | emergency stop | immediate review | Project Owner or explicitly chartered emergency release authority with independent security/technical verification |

Numeric durations SHALL be defined per Approved deployment profile before activation. Absence of a value prohibits autonomous use of that class.

Catalog identifiers are immutable and SHALL not be reassigned. Approval of a Catalog entry does not activate it.
