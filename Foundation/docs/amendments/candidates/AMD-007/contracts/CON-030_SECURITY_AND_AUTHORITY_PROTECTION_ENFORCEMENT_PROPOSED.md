# CON-030 — Security and Authority Protection Enforcement

**Identifier:** CON-030 — Proposed Reservation  
**Version:** Proposed 1.0  
**Status:** Proposed

Defines how FFG restrictions constrain identity, credentials, sessions, delegation, secret/key use, permissions, and execution boundaries through Security and AUT-001.

Every enforcement request requires restriction, jurisdiction, authority chain, target, denied/preserved actions, consequence, time/review, evidence, and recovery prerequisites. Security/AUT-001 SHALL verify mandate and current state, revoke or narrow only within jurisdiction, preserve non-waivable controls, propagate dependent restriction, and report actual outcome. FFG cannot grant authority; Security cannot release FFG conditions.
