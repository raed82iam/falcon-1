## 1. Purpose

GLO-001 defines governed terminology needed for the AMD-008 alignment package.

It exists to stabilize meaning, not to create requirements.

## 2. Scope

The glossary governs:

- Falcon Foundation;
- Falcon Application;
- MSA;
- LSA;
- CSA;
- Foundation Self-Awareness;
- Application Self-Awareness;
- documentary activation;
- coordinated documentary activation;
- historical record; and
- no-change decision terminology.

## 3. Non-Scope

The glossary does not:

- define runtime behavior;
- define authority;
- define architecture;
- create specifications; or
- authorize Stage 1.

## 4. Normative Requirements

- **GLO-001-REQ-001:** Every glossary term SHALL have one controlled meaning.
- **GLO-001-REQ-002:** Controlled terms SHALL not be reinterpreted silently.
- **GLO-001-REQ-003:** Historical terms SHALL preserve decision-time meaning.
- **GLO-001-REQ-004:** A glossary term SHALL not create authority merely by existing.
- **GLO-001-REQ-005:** Application terms SHALL remain distinct from Foundation terms where boundaries differ.

## 5. Invariants

1. Meaning first, implementation later.
2. Glossary is not authority.
3. Historical meaning stays historical.

## 6. Acceptance Evidence

Acceptance requires a glossary that can be used consistently across TREE-001, SPEC-000, CON-023, and the AMD-008 alignment documents.
