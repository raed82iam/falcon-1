## 4. Authority State

Approval of a work plan defines how authorized work must proceed. It does not itself authorize that work.

No Foundation Preparation Authority Instrument, Enabling-Provider Candidate Authority Instrument, Verification Execution Authority Instrument, Profile Activation Authority Instrument, or Foundation Implementation Authority Instrument is issued by this Approval.

## 5. Boundaries

This Approval does not:

- authorize preparation execution;
- authorize tool acquisition or environment creation;
- authorize candidate construction;
- activate a Provider, Profile, Environment, Build Baseline, Pipeline, or trace artifact;
- authorize FRS-001 source implementation;
- authorize production;
- authorize financial connectivity; or
- authorize financial activity.
