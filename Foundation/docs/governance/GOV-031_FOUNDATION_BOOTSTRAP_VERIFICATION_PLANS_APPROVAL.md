- establishes the mandatory sequence and dependency gates;
- establishes independent verification and reconstruction obligations;
- prohibits candidate self-validation and self-Activation; and
- authorizes traceability and dependent-document preparation against these plans.

## 4. Boundaries

This Approval does not:

- authorize execution of a plan;
- issue a Verification Execution Authority Instrument;
- create or activate an environment;
- validate or activate a candidate;
- activate a Build Baseline, Pipeline, Gate Profile, or trace artifact;
- authorize FRS-001 implementation;
- authorize production;
- authorize financial connectivity; or
- authorize financial activity.
