## 3. Approved Architectural Direction

- Falcon Foundation is the independent, domain-neutral operating-system foundation.
- each Falcon Application owns exactly one MSA;
- every major Application branch owns exactly one LSA responsible for that branch;
- CSA remains optional for eligible intelligent components only;
- self-development escalation begins at the actual proposal origin;
- FSA performs final OS-governance and compatibility review only;
- FSA review does not grant documentary activation, implementation, deployment, or production adoption;
- final activation and adoption require separately authorized Project Owner and governance decisions.
