## 1. Authority declaration

The Project Owner approves a timing amendment to GOV-092 so that the frozen CDA-AMD008-001 documentary activation may execute during the approved window without changing any non-timing term of GOV-092.

## 2. Authorized execution window

- Start: `2026-07-31 22:50:00 +03:00`
- End: `2026-07-31 23:30:00 +03:00`

The exact effective documentary instant SHALL be the actual execution-start timestamp recorded during this window.

## 3. Authority scope

This authority SHALL be limited to:

- amending only the timing restriction of GOV-092;
- executing the frozen 27-document CDA-AMD008-001 baseline documentary activation within the authorized window;
- preserving GOV-063 as the architectural approval authority; and
- preserving GOV-092 as the coordinated documentary activation authority.

## 4. Explicit non-authorities

This authority SHALL NOT:

- modify the frozen document content, paths, versions, manifests, or SHA-256 digests;
- grant implementation authority;
- grant code modification authority;
- grant verification execution authority;
- grant deployment authority;
- grant runtime authority;
- grant external-connection authority;
- grant financial authority;
- authorize application activation;
- start Stage 3 WP-03; or
- claim retroactive activation.
