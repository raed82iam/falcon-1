## 3. Custody Profile State

The custody profiles defined by DESIGN-SEC-001 remain in their declared `APPROVED` or `DRAFT` lifecycle states.

None is `ACTIVE`.

`FALCON-CRYPTO-1` remains `APPROVED`, not `ACTIVE`.

## 4. Consequence

The provider boundary, Windows and Linux custody models, root separation, key lifecycle, nonce, rotation, revocation, recovery, failure, and restoration design are now binding within the non-financial Foundation scope.

## 5. Boundaries

This Approval does not:

- create, import, or generate key material;
- install or configure a provider;
- activate a Custody Profile;
- activate `FALCON-CRYPTO-1`;
- authorize cryptographic operations;
- authorize implementation;
- authorize production; or
- authorize financial activity.
