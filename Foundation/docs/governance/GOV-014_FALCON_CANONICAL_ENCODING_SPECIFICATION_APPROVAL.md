## 3. Registration Decision

FCE-001 is registered as the sole canonical-encoding authority within its Approved representation scope.

TREE-001 version 1.1 adds the `FCE — Canonical Representation` domain required by the permanent `FCE-001` identifier.

This domain addition does not transfer semantic authority from CRY, IDN, TIM, FIL, SEC, or any other governing domain.

## 4. Consequence

FCE-001 v1.0 now governs canonical representation for Cryptographic Domain Context, operational identifiers, canonical timestamps, Runtime Epoch IDs, and protected or signed Time Observations.

Catalogs continue to govern values and meaning. FCE-001 governs exact representation.

- authorize financial activity.
