## 3. Registration Decision

PIPE-001 is registered in SPEC-000 as the governing Foundation Pipeline Specification.

TREE-001 version 1.2 adds the `PIPE — Build, Verification, and Promotion` domain required by the permanent `PIPE-001` identifier.

PIPE owns pipeline execution semantics. It does not take requirement ownership from governing Specifications, Contracts, Standards, VPLs, Catalogs, or authorities.

## 4. Gate Profile State

All initial Gate Profiles defined by PIPE-001 remain `PROPOSED`.

No Hotfix or Emergency Recovery Gate Profile is approved.

No Pipeline Definition, runner, provider adapter, evidence schema, or promotion path is `ACTIVE`.

## 5. Consequence

Build Intent, Gate Profile, Evidence Requirement Set, Verification Session, stage, Evaluation Context, Root Verification Evidence Set, completeness, authority separation, challenge, failure, portability, and promotion requirements are now binding within the non-financial Foundation scope.

## 6. Boundaries

This Approval does not:

- activate a Gate Profile;
- activate a Pipeline Definition;
- execute a pipeline;
- install or download a tool;
- resolve BLD-001 deliberate blocks;
- approve TRC-001 or ENV-001;
- appoint Evaluation, Completeness, Acceptance, or Promotion Authority;
- authorize implementation;
- authorize artifact promotion;
- authorize production; or
- authorize financial activity.
