## 3. Consequence

Falcon adopts staged separation between:

- Foundation Preparation Authority;
- Enabling-Provider Candidate Authority;
- Verification Execution Authority;
- Profile Activation Authority;
- Foundation Implementation Authority; and
- Operational Authority.

Preparation is not implementation. Candidate execution is not Activation. Activation is not Operational Authority.

## 4. Amendment Authority

This Acceptance authorizes preparation of the coordinated amendment package identified by ADR-I008.

Every amendment remains non-operative until separately reviewed, approved, versioned, and activated according to its authority.

## 5. Boundaries

This Acceptance does not:

- issue a Preparation Authority Instrument;
- issue Candidate Implementation Authority;
- activate a Profile;
- download or install a tool;
- create an environment;
- authorize Falcon behavior implementation;
- authorize production;
- authorize financial connectivity; or
- authorize financial activity.
