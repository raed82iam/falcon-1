## 3. Effect

This Approval:

- establishes Windows as the initial Foundation platform without making it a permanent Falcon dependency;
- records Oracle Cloud Infrastructure as the intended first future cloud direction, subject to separate governed admission;
- activates the candidate Provider and custody design boundary under AMD-003;
- activates platform-neutral Contract and Adapter isolation;
- activates synthetic-only, non-promotion, two-control, self-certification, failure, quarantine, cleanup, and exact Activation rules;
- preserves DESIGN-SEC-001 v1.0 decisions not expressly amended; and
- authorizes dependent-document and traceability updates.

## 4. Provider, Platform, and Material State

Approval of this Design establishes governed design meaning.

It does not activate:

- a Windows deployment profile;
- an Oracle Cloud deployment profile or resource;
- a Cryptographic, Secret, Certificate and Identity, or Randomness Provider;
- a custody or Crypto Profile;
- a Provider Adapter; or
- any root, key, secret, certificate, identity, trust anchor, nonce, entropy source, or other security material.

Each applicable subject requires separate authority, verification, and an exact Activation Decision.

## 5. Boundaries

This Approval does not:

- provision Windows or Oracle Cloud infrastructure;
- create, import, migrate, rewrap, promote, or activate security material;
- issue an Authority Instrument;
- authorize candidate construction or verification execution;
- establish security validity, trust, completeness, operational fitness, or cloud readiness;
- authorize implementation;
- authorize production;
- authorize financial connectivity; or
- authorize financial activity.
