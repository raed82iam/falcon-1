## 3. Baseline State

`FALCON-BUILD-FOUNDATION-1` is `APPROVED`, not `ACTIVE`.

The exact values approved by BLD-001 may be used to prepare PIPE-001, TRC-001, ENV-001, acquisition evidence, and activation verification.

Entries declared `DRAFT` in BLD-001 remain unapproved for execution.

## 4. Deliberate Blocks

Approval preserves the unresolved controls listed by BLD-001, including:

- exact Windows and Linux runner profiles;
- exact secret and binary vulnerability scanners;
- exact coverage, provenance, and attestation tools;
- exact acquired-content digests;
- PIPE-001;
- TRC-001;
- ENV-001; and
- explicit implementation authority.

No Release Candidate baseline may become active while a mandatory capability remains unresolved.

## 5. Consequence

The selected SDK, runtime, language, build, test, SBOM, database, source, isolation, reproducibility, dependency, evidence, and tool-lifecycle rules are now binding within the non-financial Foundation scope.

Future tool or version changes require governed amendment, verification, Approval, and explicit Activation.

## 6. Boundaries

This Approval does not:

- install or download a tool;
- acquire packages or runner images;
- approve an unresolved `DRAFT` tool;
- record unverified content digests;
- activate `FALCON-BUILD-FOUNDATION-1`;
- approve PIPE-001, TRC-001, or ENV-001;
- authorize implementation;
- authorize artifact promotion;
- authorize production; or
- authorize financial activity.
