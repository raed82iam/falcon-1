## 3. Consequence

Implementation work shall follow IMP-001 stages, scope exclusions, stop rules, evidence obligations, and verification gates.

No stage may introduce financial behavior, live-capital exposure, external financial connectivity, or an undeclared authority or interaction.

## 4. Remaining Gate

This approval does not grant implementation authority.

Before source implementation:

1. every required Stage 0 technical ADR shall be Accepted;
2. the exact implementation baseline shall be identified;
3. the isolated non-financial environment shall be verified; and
4. the Project Owner shall record explicit implementation authorization.
